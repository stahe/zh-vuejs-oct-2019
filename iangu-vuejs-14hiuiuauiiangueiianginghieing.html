    16. 项目 [vuejs-14]：使会话对象具备响应式特性

    我们看到，上一个项目中使用的 [session] 对象具有非响应式属性：如果修改这些属性，使用这些属性的视图将不会更新。如果我们将 [session] 对象存储在视图的响应式数据中，就可以使其成为响应式的。这就是 [vuejs-14] 项目所演示的内容。

    该项目的目录结构如下：

    16.1. [session] 对象

    所有组件共享的 [session] 对象保持不变。

    16.2. [./plugins/pluginSession] 插件

    [pluginSession] 脚本保持不变。共享的 [session] 对象可通过所有组件的 [$session] 属性访问。

    16.3. 主脚本 [main.js]

    主脚本 [main.js] 保持不变。

    16.4. 主视图 [App]

    [App] 视图现如下所示：

    
<template>
  <div class="container">
    <b-card>
      <!-- message -->
      <b-alert show variant="success" align="center">
        <h4>[vuejs-14] : utilisation d'un objet partagé entre composants</h4>
      </b-alert>
      <!-- table HTML -->
      <Table/>
    </b-card>
  </div>
</template>
 
<script>
import Table from "./components/Table";
export default {
  // nom
  name: "app",
  // composants
  components: {
    Table
  },
  // cycle de vie
  created() {
    // génération du tableau des simulations
    this.$session.generateLignes();
  }
};
</script>

    评论

    • 第 9 行：[Table] 组件不再发出 [updateTable] 事件，该事件会触发 [Table] 组件的重新生成。因此，已移除了 [updateTable] 方法；

    16.5. [Table] 组件

    [Table] 组件的演变如下：

    
<template>
  <div>
    <!-- liste vide -->
    <template v-if="lignes.length==0">
      <b-alert show variant="warning">
        <h4>Votre liste de simulations est vide</h4>
      </b-alert>
      <!-- bouton de rechargement-->
      <b-button variant="primary" @click="rechargerListe">Recharger la liste</b-button>
    </template>
    <!-- liste non vide-->
    <template v-if="lignes.length!=0">
      <b-alert show variant="primary" v-if="lignes.length==0">
        <h4>Liste de vos simulations</h4>
      </b-alert>
      <!-- tableau des simulations -->
      <b-table striped hover responsive :items="lignes" :fields="fields">
        <template v-slot:cell(action)="row">
          <b-button variant="link" @click="supprimerLigne(row.index)">Supprimer</b-button>
        </template>
      </b-table>
    </template>
  </div>
</template>
 
<script>
export default {
  // calculated state
  computed: {
    lignes() {
      return this.session.lignes;
    }
  },
  // inner state
  data() {
    return {
      fields: [
        { label: "#", key: "id" },
        { label: "Marié", key: "marié" },
        { label: "Nombre d'enfants", key: "enfants" },
        { label: "Salaire", key: "salaire" },
        { label: "Impôt", key: "impôt" },
        { label: "", key: "action" }
      ],
      session : {}
    };
  },
  // life cycle
  created(){
    this.session=this.$session
  },
  // methods
  methods: {
    supprimerLigne(index) {
      // eslint-disable-next-line
      console.log("Table supprimerLigne", index);
      // delete the line
      this.session.deleteLigne(index);
    },
    // reload displayed list
    rechargerListe() {
      // eslint-disable-next-line
      console.log("Table rechargerListe");
      // the list of simulations is generated
      this.session.generateLignes();
    }
  }
};
</script>

    注释：

    • 新功能位于第 49–51 行：当视图创建时，会话 [this.$session] 被存储在第 45 行的 [session] 属性中。置于此处的 [session] 属性是响应式的；
    • 第 58 行和第 65 行：我们不再使用 [this.$session] 向表格中添加或移除行，而是使用响应式属性 [this.session]；
